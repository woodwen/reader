## ADDED Requirements

### Requirement: 书源管理提供显式可用检测入口

书源管理 SHALL 提供用户可见的书源可用检测入口，支持检测单个书源，并支持检测当前列表范围内的多个书源。

#### Scenario: 用户检测单个书源

- **WHEN** 用户在书源管理列表中对某个 `BookSource` 执行检测
- **THEN** 应用只检测该书源
- **AND** 检测过程中展示该书源正在检测的状态
- **AND** 检测完成后展示该书源的可用或失效结果

#### Scenario: 用户检测当前列表范围

- **WHEN** 用户在书源管理页面执行批量检测
- **THEN** 应用检测当前搜索条件下列表中展示的书源
- **AND** 搜索条件为空时检测全部书源
- **AND** 应用展示总数、已完成数量和当前检测书源

#### Scenario: 当前没有可检测书源

- **WHEN** 用户执行检测
- **AND** 当前检测范围内没有书源
- **THEN** 应用不发起网络请求
- **AND** 应用提示当前没有可检测书源

### Requirement: 检测链路验证书源可阅读性

书源可用检测 SHALL 验证书源能完成可阅读链路，而不只是验证入口 URL 有非空 HTTP 响应。

#### Scenario: 搜索链路完整可读

- **WHEN** 书源支持搜索规则
- **AND** 使用检测关键词能返回至少一本书
- **AND** 应用能加载该书详情、目录和首章正文
- **AND** 首章正文非空
- **THEN** 该书源检测结果为可用

#### Scenario: 搜索无结果但发现链路可读

- **WHEN** 书源支持搜索和发现
- **AND** 使用检测关键词搜索没有返回书籍
- **AND** 发现入口返回至少一本书
- **AND** 应用能加载该书详情、目录和首章正文
- **AND** 首章正文非空
- **THEN** 该书源检测结果为可用

#### Scenario: 书源缺少必要阅读规则

- **WHEN** 书源缺少搜索和发现入口
- **OR** 书源缺少详情、目录或正文解析所需规则
- **THEN** 该书源检测结果为失效
- **AND** 失败原因说明缺少必要规则

#### Scenario: 链路任一阶段失败

- **WHEN** 搜索、发现、详情、目录或正文加载任一阶段失败、超时或返回空结果
- **THEN** 该书源检测结果为失效
- **AND** 失败原因包含失败阶段的可读摘要

### Requirement: 检测进度和取消操作可见

书源可用检测 SHALL 在用户界面展示检测进度，并允许用户取消未完成的检测。

#### Scenario: 批量检测进行中

- **WHEN** 批量检测已开始且尚未完成
- **THEN** 应用展示检测总数、已完成数量和当前检测书源
- **AND** 用户仍可识别检测正在进行
- **AND** 用户可以取消剩余检测

#### Scenario: 用户取消检测

- **WHEN** 用户取消批量检测
- **THEN** 应用停止尚未开始或尚未完成的检测任务
- **AND** 已完成检测结果保持可见
- **AND** 应用展示已完成、失败和已取消数量摘要

### Requirement: 检测结果持久化并自动禁用失效源

书源可用检测 SHALL 持久化用户可见结果；检测失败时 SHALL 自动禁用失效源，但不得删除书源或覆盖用户原有规则配置。

#### Scenario: 检测失败

- **WHEN** 某个书源检测结果为失效
- **THEN** 应用保留该书源记录
- **AND** 应用为该书源添加用户可见的“失效”标记
- **AND** 应用写入或更新检测错误摘要
- **AND** 应用保留用户原有注释内容
- **AND** 应用将该书源的 `enabled` 状态更新为 `false`
- **AND** 应用在检测完成摘要中展示自动禁用数量

#### Scenario: 检测成功

- **WHEN** 某个书源检测结果为可用
- **THEN** 应用移除此前由检测写入的“失效”标记
- **AND** 应用清理此前由检测写入的错误摘要
- **AND** 应用不会自动将原本禁用的书源重新启用

### Requirement: 检测实现保持既有分层边界

书源可用检测 SHALL 复用现有 Repository、网络请求和规则解析边界，避免 UI 直接执行网络或解析细节。

#### Scenario: UI 触发检测

- **WHEN** 书源管理 UI 触发单源或批量检测
- **THEN** UI 将用户意图交给 `BookSourceViewModel`
- **AND** `BookSourceViewModel` 负责检测任务状态、进度和取消
- **AND** `BookSourceRepository` 负责书源读取、检测链路和检测结果持久化
- **AND** 网络请求和规则解析继续通过现有 `HtmlService`、`SourceUrlRule` 或 `RuleBookParse` 路径完成

#### Scenario: 检测结果不改变其他入口边界

- **WHEN** 书源检测完成
- **THEN** 书城仍只消费已启用且支持发现的书源
- **AND** 书架远程搜索仍按已启用且支持可读搜索的书源聚合
- **AND** 历史书架书籍不会因为检测失败被自动删除、迁移或改写来源

# M-2(feat): 增加书源管理并接入搜索阅读

背景:
- reader 现有书城只支持内置固定解析器，无法像 story 一样管理和导入动态书源。
- 本次目标是在不迁移或重建既有书架、章节表的前提下，补齐书源管理到搜索阅读的最小闭环。

方案概述:
- 新增 Room `book_sources` 表和动态书源规则模型，固定源继续保留原有 key 和解析逻辑。
- 动态源内部使用 `bookSourceUrl` 作为 key，UI 展示 `bookSourceName`，避免同名源混淆。
- 在“我”页提供书源管理入口，导入、编辑、启停后立即影响书城源选择列表。

实现改动:
- 新增 `BookSource`、规则实体、`BookSourceDao`、`MIGRATION_1_2`，数据库版本升级到 2。
- 新增 `BookSourceImporter`，支持新旧书源 JSON、数组、`sourceUrls` 订阅、HTTP(S) URL、`yuedu://booksource/importonline?src=...`。
- 新增 `RuleBookParse` 和规则分析工具，支持动态源关键词搜索、详情、目录、正文解析及相对 URL 拼接。
- 扩展 `HtmlClient`、`SquareRepository/ViewModel/Fragment`，让书城显示固定源 + 已启用动态源；动态源仅支持关键词搜索。
- 新增书源管理页、编辑页、二维码扫描页，相机扫码和相册二维码结果统一走导入 parser。
- 新增 JVM 单测和可复用的真机 instrumentation 验收测试。

测试计划(UT):
- 已运行 `./gradlew :app:testDebugUnitTest :app:assembleDebug :app:compileDebugAndroidTestKotlin`。
- JVM 单测覆盖导入 parser、动态规则解析、迁移 SQL。
- 真机已安装主 APK 并验证“我”页入口、书源管理页、`yuedu://` 深链导入和启用状态展示。
- `connectedDebugAndroidTest` 因设备策略阻止测试 APK 安装而未完成，设备返回 `INSTALL_FAILED_USER_RESTRICTED: Install canceled by user`。

影响范围(建议手动测试范围):
- 重点手动验证“全文阅读 / 笔趣阁”固定源搜索阅读仍可用。
- 手动验证动态源导入、启停、编辑、删除、关键词搜索、详情、开始阅读。
- 手动验证二维码相机扫码和相册二维码解析。

风险与后续:
- 当前动态规则解析覆盖常用 CSS/XPath/JsonPath/Regex 和基础替换，不包含 story 的登录、发现页、调试页、校验服务、批量导出/分享。
- 动态源分类第一版显示“仅搜索”，后续如需要可继续接入 `exploreUrl/ruleExplore`。
